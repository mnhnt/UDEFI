# UDEFI — обои, темы и проверка железа

> «К чёрту игровых бюджетников и переплаты за наклейки. Берём нормальное железо и настраиваем под себя.»

**UDEFI** — открытая утилита для владельцев ноутбуков DNS, DEXP, Clevo, Hasee и других платформ эпохи **2010–2014 годов** (и новее). Без слежки, рекламы и лишнего мусора.

### Что умеет UDEFI:
* **Народный стиль:** установка кастомных обоев на рабочий стол в 1 клик (с автоматическим сохранением старых).
* **Рентген железа:** показывает реальную материнскую плату (Clevo, Pegatron, Quanta), определяет, полноценный у тебя процессор (`H/HQ/MQ`) или энергосберегающий (`U`), и проверяет видеокарту.
* **Для корпоративных:** зашёл с HP, ASUS, Lenovo, MSI или Acer и хочешь вернуть заводской вид? Выбираешь свой бренд во вкладке — программа ставит родные обои из папки `corporate_themes` и даёт шпаргалку по настройке.

### Как запустить:
1. Переходи во вкладку **Releases** справа.
2. Скачивай `UDEFI.exe`.
3. Запускай (устанавливать Python не нужно).
